# Controlled vocabulary policy

Every term must carry a source status and version date.

- `official_public`: reproduced directly from a public machine-readable KTBL source under compatible terms.
- `separate_ktbl_resource`: derived from a named KTBL resource outside the current BEK livestock method.
- `project_defined_crosswalk`: a local interoperability mapping that requires scientific review.
- `unverified`: placeholder prohibited from production export.

The initial CSV is deliberately small. It demonstrates governance and does not claim to enumerate every KTBL animal or housing category.
