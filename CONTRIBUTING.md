# Contributing

Contributions are welcome when they preserve scientific traceability.

Every new adapter or field mapping should include:

1. a synthetic test fixture
2. expected units and time basis
3. instrument or source-specific assumptions
4. explicit QA behaviour
5. source URL, version date and classification status
6. a test for invalid or missing data

Do not commit confidential farm data, personal identifiers, credentials, unpublished project data or proprietary KTBL database contents. Raw observations must not be silently overwritten or deleted.
