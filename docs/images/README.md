# Portfolio images

Add selected public portfolio photographs here.

The first supported filename is `portrait.jpg`. Once present, replace the `.portrait-slot` placeholder in `docs/index.html` with:

```html
<figure class="portrait">
  <img src="images/portrait.jpg" alt="Harsh Sahu working with livestock-emissions measurement equipment">
</figure>
```

Before publishing a photo, confirm that you own it or have permission to publish it and that no confidential farm, participant, instrument-screen or project data are visible.
